# Akramul Hasan — Personal Portfolio & CV Website

Responsive multi-page portfolio website built with HTML5, CSS3 and vanilla JavaScript.

## Pages
- index.html — Home
- about.html — About
- services.html — Services
- portfolio.html — Portfolio
- resume.html — Resume / CV overview
- contact.html — Contact details and enquiry form

## Run locally
Extract the ZIP and open `index.html` in a browser. For development, use VS Code with Live Server.

## Customize before publishing
1. Replace the sample portrait with your own professional photo.
2. Replace demo portfolio cards/images with screenshots and live links to your real projects.
3. Verify and update email, WhatsApp and Freelancer profile links.
4. Add verified education, employment dates, certifications and project outcomes to `resume.html`.
5. The contact form is front-end demo only. Connect Formspree, EmailJS or your own backend to receive messages.
6. Add your domain, hosting, privacy policy and analytics if needed.

Google Fonts and Unsplash images load externally, so an internet connection is required for those assets.
